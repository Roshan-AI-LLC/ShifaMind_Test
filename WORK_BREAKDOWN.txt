PART 2 — ML Serving: Phase 1 Model + Predict Endpoint + Workspace UI
================================================================================
Goal: Doctors can input/select a note and get real ICD-10 predictions.
Branch suggestion: feat/part2-ml-workspace

MODEL
-----
- [ ] model/__init__.py
- [ ] model/phase1_model.py — ShifaMind2Phase1 class (forward-only):
      · BioClinicalBERT encoder (768-dim CLS)
      · Concept head: Linear(768, 111)
      · Concept embeddings: learnable (111, 768)
      · Cross-attention at BERT layers [9, 11]
      · Multiplicative gate: concept_scores * concept_features
      · Diagnosis head: Linear(768, 50)
- [ ] model/config.py — 111 concept names, 50 ICD-10 codes, threshold defaults
- [ ] model/icd10_descriptions.json — code → description mapping

BACKEND
-------
- [ ] backend/app/models/loader.py — load Phase 1 from S3 (or local path) at startup
- [ ] backend/app/models/inference.py — tokenize → predict → apply thresholds
- [ ] backend/app/routers/predict.py — POST /api/predict (auth required):
      · Input: {text, apply_tuned_thresholds}
      · Output: {predictions[], activated_concepts[], metadata}
- [ ] backend/app/routers/notes.py:
      · GET /api/notes — list sample notes
      · GET /api/notes/{id} — single note
- [ ] Update lifespan in main.py to load model on startup
- [ ] lib/api.ts (frontend) — FastAPI fetch wrapper

FRONTEND
--------
- [ ] lib/constants.ts — ICD-10 descriptions, concept names (111 concepts, 50 codes)
- [ ] types/index.ts — TypeScript types (Prediction, Concept, SampleNote, etc.)
- [ ] hooks/usePrediction.ts — prediction API hook
- [ ] Workspace page (app/dashboard/workspace/page.tsx) — split-pane layout
- [ ] Workspace components:
      · NoteInput.tsx — textarea + sample dropdown (8-10 notes by specialty) + token count
      · PredictionPanel.tsx — ranked ICD-10 cards with expand for concept attribution
      · ConceptPanel.tsx — all 111 concepts, active ones as teal/amber pills + bars
      · ConceptDiagnosisMap.tsx — interactive attribution (click to highlight)
      · FeedbackWidget.tsx — star rating + comment modal (UI only, wired in Part 4)

PART 3 — LLM & Chat: Streaming Conversation
================================================================================
Goal: Doctors can discuss predictions with a streaming AI assistant.
Branch suggestion: feat/part3-chat

BACKEND
-------
- [ ] backend/app/services/llm_provider.py — abstract base + factory:
      · LLMProvider ABC with async stream_chat()
      · get_llm_provider() factory (reads LLM_PROVIDER env var)
- [ ] backend/app/services/openrouter.py — OpenRouterProvider:
      · httpx, OpenAI-compatible endpoint
      · Base URL: https://openrouter.ai/api/v1
      · Model: meta-llama/llama-3.3-70b-instruct:free
      · SSE token streaming
- [ ] backend/app/services/bedrock.py — BedrockProvider:
      · boto3 bedrock-runtime converse_stream
      · Primary: meta.llama3-3-70b-instruct-v1:0
      · Fallback: anthropic.claude-sonnet-4-20250514-v1:0
- [ ] backend/app/prompts/medical.py — MEDICAL_SYSTEM_PROMPT template:
      · Slots: {clinical_note}, {predictions_formatted}, {concepts_formatted}
      · Role instructions: explain predictions, differential, evidence-based,
        AI transparency disclaimer
- [ ] backend/app/routers/chat.py — POST /api/chat (auth required):
      · Input: {message, prediction_id, session_id, stream}
      · StreamingResponse (text/event-stream)
      · SSE format: data: {"type": "token", "content": "..."}\n\n
                    data: {"type": "done", "session_id": "uuid"}\n\n
      · Create/resume chat_session, persist chat_messages to Supabase

FRONTEND
--------
- [ ] hooks/useChat.ts — SSE streaming hook:
      · fetch() + ReadableStream
      · Parse token/done events
      · Append tokens to message in real time
- [ ] Chat page (app/dashboard/chat/page.tsx) — main layout
- [ ] Chat components:
      · ChatPanel.tsx — scrollable message list + auto-scroll
      · ChatMessage.tsx — user (teal glass, right) / assistant (neutral glass, left)
      · ChatInput.tsx — input bar + send button + Enter key support
      · ContextSidebar.tsx — collapsible right panel showing active diagnoses,
                             top concepts, link back to workspace
- [ ] Workspace bottom bar — "Discuss this case →" button linking to /dashboard/chat
      with prediction_id passed as query param

DELIVERABLE: Full streaming chat with LLM grounded in predictions.
